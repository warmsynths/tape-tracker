Four-Track Emulator

This page runs the same screen and recording logic as the Tracker firmware (the same C++, compiled to WebAssembly). What you see and do here is what the device does, apart from the audio hardware.

Try this

  1. Press Rec (R), let it play a few seconds, press Stop (S).
  2. Choose the bars with the jog wheel, press button 8 (OK).
  3. Press button 6 for track 2, then Rec: it waits for the loop start and records one loop.
  4. Press the same track button again to change its source (LINE, MIC, PADS).
