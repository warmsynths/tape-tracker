Four-Track Prototype

Throwaway sketch of how recording, aligning and offsetting should feel. Not the final screen design.

The question this answers. Does this model feel right? The first part you record sets the loop. Each later part records one loop, and its first note is moved onto the loop start if it lands close enough. You can then shift any part in milliseconds or bars. Play it with the keyboard, or use the walkthroughs below to see the awkward cases without needing good timing.
